# おくすりメモ

服用予定と、当日の服用済み記録をブラウザ内に保存する小さなリマインダーです。

## 使い方

`index.html` をブラウザで開きます。通知はブラウザで許可し、ページを開いている間に予定時刻を確認します。

## クラウド同期を有効にする

1. Supabaseでプロジェクトを作成し、`supabase-schema.sql` をSQL Editorで実行します。
2. SupabaseのProject URLとanon keyを `src/cloud.js` の `CLOUD_CONFIG` に設定します。
3. HTTPSで公開したページを開き、メールアドレスで登録・ログインします。

接続情報が未設定の場合は、これまでどおり端末内保存として動作します。

> これは服薬管理を補助するツールです。服用量や方法の判断には使わず、処方箋・薬剤師・医師の指示を優先してください。
